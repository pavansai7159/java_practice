Data Structures & Algorithms

Easy

Easy 💡 Conceptual

What is the time complexity of binary search?

Answer: O(log n) — each step halves the search space.
Easy 💡 Conceptual

Difference between Stack and Queue?

Answer: Stack is LIFO (Last In First Out); Queue is FIFO (First In First Out).
Easy 💻 Coding

Implement a stack using two queues.

Answer: Use two queues; for push O(1), for pop dequeue all but last element.
class StackUsingQueues {
    Queue<Integer> q1 = new LinkedList<>(), q2 = new LinkedList<>();
    void push(int x) { q1.add(x); }
    int pop() {
        while (q1.size() > 1) q2.add(q1.poll());
        int top = q1.poll();
        Queue<Integer> tmp = q1; q1 = q2; q2 = tmp;
        return top;
    }
}

Medium

Medium 💡 Conceptual

Explain how a HashMap works internally in Java.

Answer: HashMap uses array of buckets (linked list / tree). Key hashCode determines bucket index. Chain or tree handles collisions. Load factor 0.75 triggers resize.
Medium 💻 Coding

Find the longest substring without repeating characters.

Answer: Sliding window with a HashSet — O(n) time, O(k) space (k = charset size).
int lengthOfLongestSubstring(String s) {
    Set<Character> set = new HashSet<>();
    int l = 0, max = 0;
    for (int r = 0; r < s.length(); r++) {
        while (set.contains(s.charAt(r))) set.remove(s.charAt(l++));
        set.add(s.charAt(r));
        max = Math.max(max, r - l + 1);
    }
    return max;
}
Medium 💻 Coding

Detect a cycle in a linked list (Floyd's algorithm).

Answer: Use slow and fast pointers. If they meet, a cycle exists.
boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next; fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

Hard

Hard 💡 Conceptual

What is amortized complexity? Give an example.

Answer: Average cost per operation over a sequence. ArrayList.add() is O(1) amortized — doubling happens rarely enough to average out.
Hard 💻 Coding

Implement LRU Cache (O(1) get & put).

Answer: Use a HashMap + Doubly Linked List. Head = MRU, Tail = LRU.
class LRUCache {
    int cap; Map<Integer,Node> map = new HashMap<>();
    Node head = new Node(0,0), tail = new Node(0,0);
    LRUCache(int cap) { this.cap=cap; head.next=tail; tail.prev=head; }
    public int get(int key) {
        if (!map.containsKey(key)) return -1;
        Node n = map.get(key); remove(n); insert(n); return n.val;
    }
    public void put(int key, int val) {
        if (map.containsKey(key)) remove(map.get(key));
        Node n = new Node(key,val); insert(n); map.put(key,n);
        if (map.size()>cap) { Node lru=tail.prev; remove(lru); map.remove(lru.key); }
    }
    void remove(Node n){ n.prev.next=n.next; n.next.prev=n.prev; }
    void insert(Node n){ n.next=head.next; n.prev=head; head.next.prev=n; head.next=n; }
    class Node{ int key,val; Node prev,next; Node(int k,int v){key=k;val=v;} }
}

Java – Core & J2EE

Easy

Easy 💡 Conceptual

What is the difference between JDK, JRE, and JVM?

Answer: JVM executes bytecode; JRE = JVM + libraries; JDK = JRE + dev tools (javac, jar).
Easy 💡 Conceptual

What are the four OOP pillars in Java?

Answer: Encapsulation, Inheritance, Polymorphism, Abstraction.
Easy 💻 Coding

Show method overloading vs. overriding.

Answer: Overloading = same name, different params (compile-time). Overriding = subclass re-implements parent method (runtime).
class Animal { String speak() { return "..."; } }
class Dog extends Animal {
    @Override String speak() { return "Woof"; }     // overriding
    String speak(int times) { return "Woof".repeat(times); } // overloading
}

Medium

Medium 💡 Conceptual

Explain Java Memory Model: Heap vs Stack.

Answer: Stack stores method frames & local primitives (thread-local). Heap stores objects (shared). GC reclaims heap. Metaspace holds class metadata (Java 8+).
Medium 💻 Coding

Demonstrate a custom functional interface with lambda.

Answer: Functional interface has exactly one abstract method; used with lambdas/method refs.
@FunctionalInterface
interface Transformer<T, R> { R transform(T input); }

Transformer<String, Integer> len = String::length;
System.out.println(len.transform("hello")); // 5
Medium 💡 Conceptual

What is the difference between synchronized method and synchronized block?

Answer: Synchronized method locks the whole object (or class for static). Synchronized block allows locking only a specific critical section reducing contention.

Hard

Hard 💡 Conceptual

Explain Java's happens-before relationship and volatile.

Answer: Happens-before guarantees memory visibility. volatile ensures reads/writes go to main memory, preventing reordering. Not sufficient for compound actions like i++.
Hard 💻 Coding

Implement a thread-safe Singleton using double-checked locking.

Answer: volatile + double-check ensures the instance is fully constructed before being visible to other threads.
public class Singleton {
    private static volatile Singleton instance;
    private Singleton() {}
    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) instance = new Singleton();
            }
        }
        return instance;
    }
}

Python

Easy

Easy 💡 Conceptual

What are Python's mutable vs immutable types?

Answer: Immutable: int, float, str, tuple, frozenset. Mutable: list, dict, set. Immutable objects cannot be changed after creation.
Easy 💻 Coding

Write a list comprehension with filtering.

Answer: List comprehensions are concise and faster than equivalent for-loops.
# Squares of even numbers
evens_sq = [x**2 for x in range(20) if x % 2 == 0]
print(evens_sq)  # [0, 4, 16, 36, ...]

Medium

Medium 💡 Conceptual

Explain Python's GIL and its impact on multi-threading.

Answer: Global Interpreter Lock allows only one thread to execute Python bytecode at a time. For CPU-bound tasks use multiprocessing; for I/O-bound tasks threading still works well.
Medium 💻 Coding

Implement a decorator that measures function execution time.

Answer: Decorators wrap a function to add behaviour without modifying its source.
import time, functools
def timer(fn):
    @functools.wraps(fn)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = fn(*args, **kwargs)
        print(f"{fn.__name__} took {time.perf_counter()-start:.4f}s")
        return result
    return wrapper

@timer
def heavy(): time.sleep(0.5)

Hard

Hard 💻 Coding

Implement an async HTTP fetcher using asyncio + aiohttp.

Answer: asyncio event loop + aiohttp for non-blocking concurrent HTTP requests.
import asyncio, aiohttp
async def fetch(session, url):
    async with session.get(url) as r: return await r.text()
async def main(urls):
    async with aiohttp.ClientSession() as s:
        return await asyncio.gather(*[fetch(s,u) for u in urls])
# asyncio.run(main(["https://api.example.com/1","https://api.example.com/2"]))

RESTful APIs & Microservices

Easy

Easy 💡 Conceptual

What are the REST constraints / principles?

Answer: Client-Server, Stateless, Cacheable, Uniform Interface, Layered System, Code-on-Demand (optional).
Easy 💡 Conceptual

HTTP status codes: 200 vs 201 vs 204 vs 400 vs 401 vs 403 vs 404 vs 429 vs 500?

Answer: 200 OK, 201 Created, 204 No Content, 400 Bad Request, 401 Unauthorized, 403 Forbidden, 404 Not Found, 429 Too Many Requests, 500 Server Error.

Medium

Medium 💡 Conceptual

Explain the Circuit Breaker pattern in microservices.

Answer: Monitors failures; after a threshold opens the circuit (fails fast). After timeout, moves to half-open to probe recovery. Prevents cascade failures. Resilience4j & Hystrix implement this.

Hard

Hard 💡 Conceptual

SAGA pattern: choreography vs orchestration.

Answer: Choreography: services emit events, others react — decoupled but hard to trace. Orchestration: a central saga orchestrator commands each step — easier to trace but coupling. Both compensate on failure via undo transactions.

What is auto-configuration in Spring Boot?

Hard

Hard 💻 Coding

Implement Quartz Scheduler job triggered via cron.

Answer: Implement Job, configure JobDetail + CronTrigger beans.
@Component
public class ReportJob implements Job {
    @Override public void execute(JobExecutionContext ctx) {
        System.out.println("Running report: " + LocalDateTime.now());
    }
}
@Configuration
public class QuartzConfig {
    @Bean JobDetail reportJobDetail() {
        return JobBuilder.newJob(ReportJob.class)
            .withIdentity("reportJob").storeDurably().build();
    }
    @Bean Trigger reportTrigger(JobDetail d) {
        return TriggerBuilder.newTrigger().forJob(d)
            .withSchedule(CronScheduleBuilder.cronSchedule("0 0 8 * * ?")).build();
    }
}

Databases – Elasticsearch, MongoDB, Redis

Easy

Easy 💡 Conceptual

What is an inverted index in Elasticsearch?

Answer: Maps terms to the list of documents containing them, enabling full-text search in O(1) to O(log n) per term.

What is Redis used for?

Answer: In-memory key-value store used for caching, session management, pub/sub, rate limiting, leaderboards, and distributed locks.

Medium 💻 Coding

Redis distributed lock implementation in Java.

Answer: Use SET NX PX (set if not exists with expiry) for atomic lock acquisition.
// Jedis example
boolean acquireLock(Jedis j, String key, String token, long ttlMs) {
    return "OK".equals(j.set(key, token, SetParams.setParams().nx().px(ttlMs)));
}
void releaseLock(Jedis j, String key, String token) {
    String script = "if redis.call('get',KEYS[1])==ARGV[1] then return redis.call('del',KEYS[1]) else return 0 end";
    j.eval(script, 1, key, token);
}

Hard

Hard 💡 Conceptual

Explain MongoDB's WiredTiger storage engine and write concern.

Answer: WiredTiger uses MVCC, document-level locking, and compression. Write concern (w:1, w:majority, j:true) controls durability: majority ensures replication to most nodes before ack.

DevOps – Docker, Kubernetes, CI/CD

Easy

Easy 💡 Conceptual

What is the difference between Docker image and container?

Answer: Image is a read-only template (layered filesystem). Container is a running instance of an image with a writable layer on top.
Easy 💻 Coding

Multi-stage Dockerfile for a Java Spring Boot app.

Answer: Multi-stage builds keep the final image lean by discarding build tools.
# Build stage
FROM maven:3.9-eclipse-temurin-21 AS build
WORKDIR /app
COPY pom.xml . && RUN mvn dependency:go-offline
COPY src ./src
RUN mvn package -DskipTests

# Runtime stage
FROM eclipse-temurin:21-jre
WORKDIR /app
COPY --from=build /app/target/*.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java","-jar","app.jar"]

Kubernetes Deployment + HPA manifest.

Answer: HPA scales pods based on CPU utilization automatically.

kind: Deployment
metadata: { name: api-service }

  replicas: 2

Medium 💡 Conceptual

Explain Kubernetes liveness vs readiness vs startup probes.

Answer: Liveness: restarts container if unhealthy. Readiness: removes pod from Service LB if not ready. Startup: delays liveness checks for slow-starting containers.

Apache Kafka

Easy

Easy 💡 Conceptual

What are Kafka topics, partitions, and offsets?

Answer: Topic = logical stream. Partition = ordered, immutable log (enables parallelism). Offset = unique message position within a partition.

Medium

Medium 💻 Coding

Kafka producer/consumer in Java (Spring Kafka).

Answer: @KafkaListener auto-commits offset after successful processing.
// Producer
@Component public class OrderProducer {
    @Autowired KafkaTemplate<String,String> kafka;
    public void send(String order) {
        kafka.send("orders", UUID.randomUUID().toString(), order);
    }
}
// Consumer
@Component public class OrderConsumer {
    @KafkaListener(topics="orders", groupId="order-group")
    public void consume(String msg, @Header(KafkaHeaders.RECEIVED_PARTITION) int part) {
        System.out.printf("Partition %d: %s%n", part, msg);
    }
}

Hard

Hard 💡 Conceptual

Explain exactly-once semantics in Kafka.

Answer: Requires idempotent producer (enable.idempotence=true) + transactional producer + read-process-write in one transaction. Consumer must use isolation.level=read_committed.

Security – Crypto, PQC, RBAC

Easy

Easy 💡 Conceptual

Symmetric vs Asymmetric encryption?

Answer: Symmetric: same key encrypt/decrypt (AES). Fast, used for bulk data. Asymmetric: public/private key pair (RSA, EC). Slower, used for key exchange & signatures.

Medium

Medium 💻 Coding

AES-256-GCM encryption in Java.

Answer: GCM mode provides authenticated encryption (confidentiality + integrity + authenticity).
byte[] encrypt(byte[] plain, SecretKey key) throws Exception {
    byte[] iv = new byte[12]; new SecureRandom().nextBytes(iv);
    Cipher c = Cipher.getInstance("AES/GCM/NoPadding");
    c.init(Cipher.ENCRYPT_MODE, key, new GCMParameterSpec(128, iv));
    byte[] ciphertext = c.doFinal(plain);
    ByteBuffer buf = ByteBuffer.allocate(12 + ciphertext.length);
    buf.put(iv); buf.put(ciphertext);
    return buf.array();
}
Medium 💡 Conceptual

Explain RBAC and how it differs from ABAC.

Answer: RBAC assigns permissions to roles, roles to users. Simple and auditable. ABAC uses attributes (user, resource, env) for fine-grained policies. ABAC is more flexible but complex.

Hard

Hard 💡 Conceptual

What is Post-Quantum Cryptography (PQC)? What NIST algorithms were standardised?

Answer: PQC algorithms resist attacks by quantum computers (Shor's & Grover's). NIST 2024 standards: ML-KEM (CRYSTALS-Kyber) for KEM, ML-DSA (CRYSTALS-Dilithium) & SLH-DSA (SPHINCS+) for signatures. Java 21+ includes experimental PQC support.
Hard 💻 Coding

Secure API: JWT validation with RS256.

Answer: Use public key to verify JWT signature — private key never leaves auth server.
// Using java-jwt (Auth0)
RSAPublicKey pub = loadPublicKey(); // from cert/JWKS
DecodedJWT jwt = JWT.require(Algorithm.RSA256(pub, null))
    .withIssuer("https://auth.example.com")
    .build()
    .verify(token);
String userId = jwt.getSubject();

Easy 💡 Conceptual

What is the difference between EC2, ECS, and EKS?

Answer: EC2: raw VMs. ECS: managed container service (AWS-native orchestration). EKS: managed Kubernetes. ECS is simpler; EKS gives full K8s ecosystem.

Explain S3 storage classes.

Answer: Standard (frequent access), Infrequent Access, One-Zone-IA, Glacier (archival), Glacier Deep Archive, Intelligent-Tiering (auto-moves between tiers).

Medium

Medium 💻 Coding

AWS Lambda function with SQS trigger (Java).

Answer: Lambda polls SQS; batch processing with partial failure support.
public class OrderHandler implements RequestHandler<SQSEvent, SQSBatchResponse> {
    public SQSBatchResponse handleRequest(SQSEvent event, Context ctx) {
        List<SQSBatchResponse.BatchItemFailure> failures = new ArrayList<>();
        for (SQSEvent.SQSMessage msg : event.getRecords()) {
            try { processOrder(msg.getBody()); }
            catch (Exception e) {
                failures.add(SQSBatchResponse.BatchItemFailure.builder()
                    .withItemIdentifier(msg.getMessageId()).build());
            }
        }
        return SQSBatchResponse.builder().withBatchItemFailures(failures).build();
    }
}

What is VPC and explain public vs private subnets?

Networking & System Architecture

Easy

Easy 💡 Conceptual

HTTP/2 advantages over HTTP/1.1?

Answer: Multiplexing (multiple requests over one TCP connection), header compression (HPACK), server push, binary framing, stream prioritization — massively reduces latency.

Medium

Medium 💡 Conceptual

What is the CAP theorem?

Answer: A distributed system can guarantee only 2 of: Consistency (all nodes see same data), Availability (every request gets a response), Partition Tolerance (survives network splits). In practice P is unavoidable, so choose CP or AP.
Medium 💡 Conceptual

How would you design a rate limiter?

Answer: Token Bucket (burst-friendly) or Sliding Window Counter in Redis. Store count per user per window. Atomic INCR + EXPIRY. Distribute via Redis Cluster for scale. Return 429 on breach.

Hard

Hard 💡 Conceptual

Describe the design of a URL shortener at 10M req/day scale.

Answer: Write: base62 encode incremental ID (or hash). Store in Redis + DB. Read: Redis cache lookup (99% hits) → DB fallback. CDN at edge. Partitioned DB by range. Analytics via async Kafka → ClickHouse pipeline. 99.99% HA with multi-region active-active.
